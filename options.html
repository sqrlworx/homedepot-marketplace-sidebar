Home Depot → Marketplace Finder

Add a Llama API key to get LLM-generated search queries and smarter result ranking. Without a key, the extension falls back to keyword heuristics.

Stored only in this browser (chrome.storage.local) and sent directly to api.llama.com from the extension. Get one at llama.developer.meta.com.
This runs once or twice per product page. Scout is faster/cheaper if you browse a lot; Maverick gives the best match judgments. 


    

      Privacy: when a key is set, the product title and the Marketplace
      listing titles/prices/locations are sent to the Llama API (Meta) to build
      queries and rank matches. No key → nothing leaves your browser except the
      Facebook Marketplace search itself.
